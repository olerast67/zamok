Put a password on a folder in File Explorer

Right-click a folder on Windows 10 or 11 and choose “Encrypt with password”. The folder stays at its path, and the files in it are stored encrypted. To open it, double-click the lock icon inside and enter the password or use Windows Hello. When you lock the screen, the folder locks.

Encrypt, open, lock

  1. 1Encrypt

    Right-click the folder and choose “Encrypt with password”. The wizard asks for a password and offers a recovery key of 44 words.

    Zamok writes an encrypted copy to a hidden folder next to it, checks the copy and only then deletes the original.

  2. 2Open

    While the folder is locked, it shows one icon inside. Double-click it, and the password window from the top of this page opens. Windows Hello is turned on for each folder separately.

  3. 3Lock

    The folder locks by itself on Win+L, on sleep and hibernation, on sign-out and after 30 minutes without work in it. The timeout is set per folder.

    Ctrl+Alt+Shift+L locks all folders at once.

Do not drag an open folder with the mouse

Explorer copies the files to the new place unencrypted and deletes them from the vault. Lock the folder first: a locked folder has nothing to copy and stays where it is. Zamok cancels “Cut” on an encrypted folder and moving a parent folder to another drive. Windows offers no way to intercept dragging the folder itself. Other file managers do not see these checks.

What happens to your files

Where you work
In the folder at its own path. In place of the original, the WinFsp driver presents a virtual folder with the same path. Shortcuts, program projects and recent files keep working.
While the folder is open
Files are decrypted on read and encrypted on write. Zamok keeps the plaintext in memory.
If the program crashes
Before the copy is verified, Zamok rolls the work back. After that, it finishes the work.
Encryption
Cryptomator vault format 8 (AES-GCM, AES-SIV, scrypt) through the RustCrypto libraries. File contents and file names are encrypted. The name of the encrypted folder itself stays visible.
Network
There is no telemetry, no analytics, no accounts and no servers. The only network request is the “Check for updates” button in the settings: one HTTPS request to the GitHub API, sent only when you press it. GitHub sees your IP address and User-Agent: Zamok/<version>; no cookies, identifiers, folder names or paths are sent, and nothing is downloaded. This was checked in the code of 0.1.0-alpha: core/Cargo.lock has no HTTP, TLS, socket or async network crates, zamok-core and zamok-shell.dll contain no sockets, HTTP clients or web addresses, and in Zamok.exe only the button handler calls the HTTP client. Details in PRIVACY.md.

What Zamok protects against and what it does not

Protects against

  • a stolen or lost laptop that is turned off;
  • copies of the folder, USB drives, cloud storage;
  • another user of the same computer (the check with a second account is still on the roadmap);
  • someone who sits down at your computer while the folder is locked.

Does not protect against

  • malware on your computer while the folder is open;
  • someone who knows the password or your Windows Hello PIN;
  • deletion: an encrypted folder cannot be read, but it can be deleted.

Traces in Windows

Zamok writes no decrypted data to disk itself. Windows and other programs leave traces. Encrypting the system drive (BitLocker or Device Encryption) covers almost all of them if the laptop is stolen.

Opening the folder without Zamok

An encrypted folder is a standard Cryptomator vault. If Zamok stops working or you uninstall it, the data stays in the hidden folder, and a note appears next to it:

  • .Documents.zamok
  • HOW TO OPEN Documents.txt
  1. Install Cryptomator on Windows, macOS, Linux, iOS or Android.
  2. Turn on hidden and protected system files in Explorer and open vault.cryptomator from the hidden folder.
  3. Enter your password. If you forgot it, Cryptomator resets the password with the 44-word recovery key from Zamok.

Compatibility is tested in both directions against vaults made by Cryptomator 1.19.6. For the command line there is zamok-recover: it exports a decrypted copy with the password or the recovery key and is built from core/.

Without the password and without the recovery key, the data cannot be recovered. The recovery key is optional in the wizard and on by default.

Install

Download Zamok-Setup-<version>.exe from Releases. The setup program contains the WinFsp driver and installs it only if WinFsp is absent. Windows asks for administrator rights for the driver. Zamok itself installs for your user account into %LOCALAPPDATA%\Programs\Zamok.

The installer is not signed yet. SmartScreen shows “Windows protected your PC”. Check the SHA-256 listed on the release page, then choose More info and Run anyway:

Get-FileHash .\Zamok-Setup-0.1.0.exe -Algorithm SHA256

Smart App Control on Windows 11 blocks unsigned programs, so Zamok cannot be installed while it is turned on. On Windows 11 the Zamok items are under “Show more options” in the right-click menu.

NTFS. USB sticks with exFAT or FAT32 are not supported yet.

Alpha version 0.1.0

Open items that matter for your data, all from the roadmap: no third-party review, no fuzzing of format parsing yet, power-loss tests on a virtual machine not done, Windows 11 and cloud clients not tested. Updates are checked only with the button in the settings, and nothing is installed automatically: you download the new version yourself and install it over the old one, which keeps your folder list.

How this was made: the author designed the app, directed the work and checked it on a real computer. Much of the code was written with an AI coding assistant (Claude by Anthropic). It has not been audited by a third party.
