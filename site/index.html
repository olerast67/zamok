Encrypt a folder from File Explorer and keep it at its path

Right-click a folder on Windows 10 or 11 and choose "Encrypt with password". To open it, double-click the lock icon inside and enter the password or use Windows Hello. When you lock the screen, the folder locks.

Free, GPL-3.0. Version 0.1.0-alpha, not audited by a third party. Keep a backup of important data outside Zamok.

Download Zamok for Windows

Do not drag an open folder with the mouse

Explorer copies the files to the new place unencrypted and deletes them from the vault. Lock the folder first: a locked folder has nothing to copy and stays where it is. Zamok cancels "Cut" on an encrypted folder and moving a parent folder to another drive. Windows offers no way to intercept dragging the folder itself.

What it protects against

Protects against

  • a stolen or lost laptop that is turned off
  • copies of the folder, USB drives, cloud storage
  • another user of the same computer (the check with a second account is still on the roadmap)
  • someone at your computer while the folder is locked

Does not protect against

  • malware on your computer while the folder is open
  • someone who knows the password or your Windows Hello PIN
  • deletion: an encrypted folder cannot be read, but it can be deleted

Traces Windows leaves

Zamok writes no decrypted data to disk itself. Encrypting the system drive with BitLocker or Device Encryption covers almost all of these traces if the laptop is stolen.

The windows

How it works

Zamok writes an encrypted copy to a hidden folder next to the original, checks the copy and then deletes the original. The WinFsp driver presents a virtual folder at the same path, so shortcuts and program projects keep working.

The folder locks on Win+L, on sleep and hibernation, on sign-out and after 30 minutes without work in it. Ctrl+Alt+Shift+L locks all folders. The programs make no network calls and have no telemetry or accounts.

Install

Download Zamok-Setup-<version>.exe. It contains the WinFsp driver and asks for administrator rights only to install it. You need Windows 10 or 11, x64, and a folder on an NTFS drive. Zamok refuses folders inside OneDrive, Dropbox and Yandex Disk for now.

The installer is not signed yet, so SmartScreen shows "Windows protected your PC". Compare the SHA-256 from the release page with the file, then choose More info and Run anyway. Smart App Control on Windows 11 blocks unsigned programs, so Zamok cannot be installed while it is on.

If Zamok stops working

An encrypted folder is a standard vault of Cryptomator format 8, in a hidden .Name.zamok folder. Open vault.cryptomator in Cryptomator on Windows, macOS, Linux, iOS or Android with your password or the recovery key. Compatibility is tested in both directions with Cryptomator 1.19.6.
