# Безопасность

Zamok шифрует файлы людей, поэтому об уязвимости лучше сначала сообщить автору лично, а не в открытой задаче.

Как сообщить: через «Report a vulnerability» на вкладке Security этого репозитория (GitHub Private vulnerability reporting). Опишите, что нашли, на какой версии и как повторить. Эта кнопка заработает, когда репозиторий станет публичным.

Что считается уязвимостью:
- способ прочитать содержимое запертой папки без пароля и ключа восстановления;
- запись расшифрованного содержимого на диск самой программой Zamok;
- потеря или порча данных при шифровании, запирании, обновлении или сбое;
- обход проверки подписи обновлений;
- доступ другого пользователя компьютера к открытой папке.

Что не считается уязвимостью, а описано в модели угроз в README: следы, которые оставляет сама Windows (кэш миниатюр, файл подкачки, файл гибернации), и вирус, который работает на компьютере, пока папка открыта.

До выхода версии 1.0 поддерживается только последняя сборка из ветки `main`.
