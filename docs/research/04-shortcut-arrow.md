# 04. Стрелка ярлыка на значке зашифрованной папки

Дата: 2026-11-08. Вопрос автора: можно ли убрать стрелку в углу значка папки Zamok.

## Что это

Папка Zamok на своём пути — точка подключения тома WinFsp (метка `IO_REPARSE_TAG_MOUNT_POINT`, DESIGN.md, раздел 3.1). Проводник рисует стрелку на любой папке с такой меткой: на junction, на точках подключения дисков, на папках Cryptomator. Проверка 2026-11-08 на Windows 10 22H2 (19045): `Shell.Application` для папки Zamok отвечает `IsLink = False`, для обычной junction `IsLink = True`, но стрелку Проводник рисует у обеих. Значит, стрелка зависит от метки на диске, а не от того, считает ли оболочка папку ярлыком.

## Варианты

| Способ | Убирает стрелку | Цена | Вывод |
|---|---|---|---|
| `desktop.ini` в корне папки | нет | | наложения (overlay) он не задаёт |
| Значение `Shell Icons\29` в HKLM (пустой значок наложения) | да | убирает стрелки у всех ярлыков в системе, нужны права администратора | не делаем: меняет чужое |
| Свой обработчик наложений (`IShellIconOverlayIdentifier`) | нет | слоты наложений заняты облачными клиентами, стрелку он не отменяет, только добавляет своё | не делаем |
| Подключать том буквой диска, а папку делать ярлыком | да | ломается главная идея «папка на своём месте»: программы и ярлыки видят другой путь | не делаем |
| Не подключать, а показывать файлы через Cloud Files API | да | расшифрованное попадает на диск (DESIGN.md, раздел 4) | не делаем |

## Решение

Стрелку оставляем. Она честно показывает, что это не обычная папка, и та же стрелка есть у Cryptomator. Убрать её можно только системной настройкой для всех ярлыков сразу, а чужие настройки Windows Zamok не трогает.
