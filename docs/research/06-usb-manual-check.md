# 06. Флешка руками: извлечение, выдёргивание, значок

Дата: 2026-11-17. Проверяли вдвоём: автор вынимал и вставлял флешку и смотрел на экран, Claude следил за core.

## Что было

- Флешка Kingston DataTraveler 3.0, exFAT, 62 ГБ, буква G:. Ночью на ней оборвалась запись файла 4,5 ГБ: Windows записала аппаратные ошибки (событие `disk` 51), флешка отключилась. После повторной вставки том помечен как «не закрыт как следует» (`fsutil dirty query`: Dirty). Новых ошибок записи за время проверки не было.
- Zamok из main после PR #63, установлен `scripts\install-dev.ps1`. Core тот, что работает у автора, со всеми его папками.
- Папка `G:\Тест Zamok`: заметка 45 байт, файл 20 МБ из случайных байт, подпапка `Фото` с файлом 512 КБ. До шифрования сняты SHA-256 всех файлов.

Следили так: раз в полсекунды спрашивали у core состояние папки по каналу и смотрели, какие флешки и буквы есть в системе. Время в журнале core в UTC, ниже местное.

## Что это закрывает

- Значок замка из `desktop.ini` на флешке виден в Проводнике: снята пометка **[проверить]** в DESIGN.md, раздел 3.6.
- «Извлечь» и выдёргивание при открытой папке: запирание сразу, буква пропадает, извлечению ничего не мешает.

## Что осталось

- Вставка под **другой** буквой на настоящей флешке: Windows запоминает букву за устройством и дала ту же G:. Смена буквы проверена только диском `subst` (`tests/core/test-letter.ps1`). Проверить можно, сменив букву флешки в «Управлении дисками» (нужны права администратора).
- FAT32, файл больше 4 ГиБ на exFAT, второй компьютер.
- `G:\zamok-test` с ночного прогона Claude удалить не смог (правило доступа), автор удаляет сам.
