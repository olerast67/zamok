# Проверки окон Zamok.exe

`test-ui.ps1`: 73 проверки настоящего `Zamok.exe` с настоящим `zamok-core`. Скрипт собирает оба (Rust release и C# Release), запускает core со своей папкой данных и своим каналом и проходит сценарии через UI Automation: вводит значения и нажимает кнопки по `AutomationId`, как экранный диктор. Клавиши на рабочий стол не посылаются, но окна Zamok на время теста появляются на экране.

- мастер шифрования: имя папки в заголовке, кнопка «Зашифровать» выключена, пока пароли не совпадают, текст надёжности из файла строк, ключ из 44 слов, неверные слова отклоняются, верные ведут к итогу, папка зашифрована и открыта, «Закрыть» закрывает окно;
- окно пароля: имя папки, неверный пароль оставляет окно и пишет «Пароль не подошёл», верный открывает папку и закрывает окно, уже открытая папка закрывает окно сама;
- вход ключом восстановления;
- ошибки: папка не зашифрована, core не запущен, файл открыт в другой программе (имя файла в окне, папка не тронута).
- доступность в каждом окне и на каждом шаге мастера: у каждого элемента, до которого доходит Tab, есть имя для экранного диктора (не ключ строки), клавиши доступа в окне не повторяются, Tab и Shift+Tab проходят все элементы по порядку и по кругу; строки ошибок и состояния читаются сами (`LiveSetting`); Enter в поле пароля открывает папку, Esc закрывает окно. Клавиши нажимаются по-настоящему (`SendInput`), только пока окно Zamok активное. Если Windows отдала клавиатуру другому окну, проверка смотрит элементы через шаблоны UI Automation и пишет в итоге, что Tab не нажимался. Клавиши доступа проверяются по свойству: буква зависит от раскладки клавиатуры;
- язык: с `ZAMOK_LANG=ru` и `en` окно говорит на своём языке, в английских окнах нет русского текста, кроме имён папок.

Все папки внутри `tests\tmp\ui`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\ui\test-ui.ps1
```

Тесты C# (`ui/Zamok.Tests`): оценка пароля, проверка 4 слов, клиент канала с настоящим core (категория `Integration`, в CI не запускается), сверка строк: у каждого кода ошибки core есть текст на русском и английском, у каждого `x:Uid` и ключа в коде есть строка на обоих языках, каждая строка где-то показывается, в разметке и коде окон нет текста мимо файла строк, тексты установщика и его окна на обоих языках. Строки core и DLL Проводника (трей, уведомления, памятка, окно DLL) проверяет `core/crates/zamok-core/tests/strings.rs`: у каждой русской строки есть английская пара с теми же подстановками.

```powershell
dotnet test ui/Zamok.Tests
```

Снимки окон для README и сайта (`docs/images/screens/ru` и `en`, сайт берёт их оттуда при сборке): `screens.ps1` с настоящими `Zamok.exe` и core со своей папкой данных и каналом. Папки выдуманные, в `C:\Demo` (скрипт создаёт её, только если её нет, и удаляет в конце). Окна снимаются через `PrintWindow`, чужие окна поверх не мешают. Ключ восстановления случайный: если в нём слово из списка, которое отвлекало бы на снимке, берётся новый. Меню Проводника снимается в процессе скрипта из пунктов установленного Zamok.

```powershell
powershell -NoProfile -Sta -ExecutionPolicy Bypass -File tests\ui\screens.ps1 -Lang ru
powershell -NoProfile -Sta -ExecutionPolicy Bypass -File tests\ui\screens.ps1 -Lang en
```
