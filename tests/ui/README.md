# Проверки окон Zamok.exe

`test-ui.ps1`: 17 проверок настоящего `Zamok.exe` с настоящим `zamok-core`. Скрипт собирает оба (Rust release и C# Release), запускает core со своей папкой данных и своим каналом и проходит сценарии через UI Automation: вводит значения и нажимает кнопки по `AutomationId`, как экранный диктор. Клавиши на рабочий стол не посылаются, но окна Zamok на время теста появляются на экране.

- мастер шифрования: имя папки в заголовке, кнопка «Зашифровать» выключена, пока пароли не совпадают, текст надёжности из файла строк, ключ из 44 слов, неверные слова отклоняются, верные ведут к итогу, папка зашифрована и открыта, «Закрыть» закрывает окно;
- окно пароля: имя папки, неверный пароль оставляет окно и пишет «Пароль не подошёл», верный открывает папку и закрывает окно, уже открытая папка закрывает окно сама;
- вход ключом восстановления;
- ошибки: папка не зашифрована, core не запущен, файл открыт в другой программе (имя файла в окне, папка не тронута).

Все папки внутри `tests\tmp\ui`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\ui\test-ui.ps1
```

Тесты C# (`ui/Zamok.Tests`): оценка пароля, проверка 4 слов, клиент канала с настоящим core (категория `Integration`, в CI не запускается), сверка строк: у каждого кода ошибки core есть текст на русском и английском.

```powershell
dotnet test ui/Zamok.Tests
```
