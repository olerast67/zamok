# Проверка расширения Проводника

`test-shell.ps1`: проверки `zamok-shell.dll` и меню папки без Проводника пользователя, всё в процессе теста. Прав администратора не нужно.

- DLL загружается в процесс теста, как в Проводник, список папок Zamok лежит в своей общей памяти (`ZAMOK_SHELL_MAP`), список работающего core не трогается. `CopyCallback` отказывает в переносе папки Zamok и её родителя на другой диск и пропускает остальное.
- 20 000 вызовов `CopyCallback` с папками Zamok и обычными: время каждого вызова по процессорному времени потока и по часам (99,9 % вызовов) меньше миллисекунды.
- На время вызовов в `ntdll` стоят перехватчики `NtCreateFile`, `NtOpenFile`, `NtQueryAttributesFile`, `NtQueryFullAttributesFile`, `NtDeviceIoControlFile`. Через них проходит любое открытие файла, канала и сокета и любой запрос атрибутов по имени. Считаются вызовы только из потока теста, их должно быть ноль. Контроль: после замера тот же поток открывает файл, и перехватчики это видят. DLL не загружает сетевые библиотеки.
- Меню папки в `tests\tmp\shell` 1000 раз подряд, как при правом клике: `IShellFolder.GetUIObjectOf(IContextMenu)` и `QueryContextMenu`. В каждом меню есть пункт Zamok, медиана последних 20 % не больше чем в 1,5 раза выше первых 20 %, дескрипторы, объекты GDI и USER и память не растут. Пункты меню берутся из установленного Zamok (реестр только читается), без установки эта часть пропускается.

```powershell
powershell -NoProfile -Sta -ExecutionPolicy Bypass -File tests\shell\test-shell.ps1
```
