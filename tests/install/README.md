# Проверка установки

`test-install.ps1`: 14 проверок полного цикла на настоящей системе. Работает с настоящим реестром HKCU и `%LOCALAPPDATA%\Programs\Zamok`, поэтому запускается только там, где Zamok не установлен и не запущен, и в конце всё удаляет.

- `install-dev.ps1`: файлы на месте, core запущен из папки установки, автозапуск, `.zamok` ведёт к `Zamok.exe --unlock`;
- в реестре добавился только пункт `ZamokEncrypt`, действия папок по умолчанию не изменились (снимок до и после);
- пункт меню Проводника «Зашифровать паролем» есть и открывает мастер, мастер шифрует папку;
- в запертой папке есть значок `Открыть <Имя>.zamok`, его открытие через сопоставление файлов показывает окно пароля, пароль открывает папку;
- удаление без `-Force` отказывается, пока есть зашифрованные папки;
- после `uninstall-dev.ps1 -Force` нет процесса, файлов, ключей реестра и автозапуска, реестр папок такой же, как до теста.

Тестовая папка только в `tests\tmp\install`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\install\test-install.ps1
```

## Установщик MSI

`test-msi.ps1`: 11 проверок установщика `installer/out/Zamok-*.msi` (собирается `installer/build-msi.ps1`). Тихая установка без прав администратора, файлы, значки собраны из значков этой Windows, core запущен через сторожа, автозапуск, пункты меню на языке Windows, `.zamok` ведёт к окну пароля, core сам ведёт условия меню; тихое удаление убирает процесс, файлы, значки и записи реестра, список папок остаётся. Запускается только там, где Zamok не установлен.
