# Проверки фонового процесса (этап 4)

`test-core.ps1`: 70 проверок `zamok-core` на настоящей системе. Скрипт собирает core, создаёт хранилище из `tests/fixtures-src/vault1` и запускает core со своей папкой данных и своим каналом (переменные `ZAMOK_DATA_DIR` и `ZAMOK_PIPE`), поэтому настоящий core на этом компьютере не мешает и не затрагивается.

Что проверяется:
- права канала: доступ только у текущего пользователя; второй core с тем же каналом не запускается;
- добавление папки: подключается запертой, в ней один значок `Открыть <Имя>.zamok`, на точке подключения атрибут «системный»; плохое хранилище, хранилище внутри папки и занятый путь отклоняются, обычная папка на пути не трогается;
- открытие паролем, по пути значка, ключом восстановления; неверный пароль и неверный ключ оставляют папку запертой;
- запирание по команде, «запереть всё», по сообщениям Windows о блокировке экрана, сне и смене пользователя (скрипт шлёт окну core те же сообщения, что Windows);
- «запереть всё» во время проверки пароля: папка в итоге заперта, открытие отменено;
- запирание по бездействию: чтение раз в секунду держит папку открытой, без обращений она запирается сама;
- открытый файл: статус называет программу (только имя exe); пора запирать по бездействию, а файл открыт: core запускает окно `--idle-lock`, ответ «Отложить» не даёт запереть 10 минут, «Запереть сейчас» запирает при открытом файле, окно закрыли без ответа: второго вопроса нет, папка запирается после закрытия файла, Win+L во время вопроса запирает сразу и закрывает окно;
- перезапуск: список и настройки сохраняются, папка подключается запертой;
- падение core: точка подключения исчезает, после запуска папка подключается снова;
- мёртвая точка подключения после выключения питания снимается при старте;
- обычная папка на месте зашифрованной: core её не трогает, папка «недоступна», после освобождения пути открывается;
- удаление из списка не трогает хранилище; в журнале нет имён папок, путей и пароля.

Запуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\core\test-core.ps1
```

Занимает около минуты. Нужен установленный WinFsp, папка `tests\tmp\core` пересоздаётся при каждом запуске.

## Шифрование на месте

`test-encrypt.ps1`: 59 проверок шифрования существующей папки (DESIGN.md, раздел 5). Все папки только внутри `tests\tmp\encrypt`, core работает со своей папкой данных и своим каналом.

- обычное шифрование: ключ восстановления из 44 слов, папка открыта на том же пути, содержимое совпадает с эталоном по SHA-256, даты файлов и атрибуты «только чтение» и «скрытый» сохранены, оригинал и временная копия удалены, Cryptomator читает результат;
- отказы проверок не трогают папку: пустой пароль, файл открыт в другой программе (с именем файла в ответе), рядом уже есть `.Имя.zamok`, папка внутри AppData;
- отмена во время копирования: оригинал цел, временная копия удалена;
- папку держит программа (текущая папка процесса): переименовать нельзя, откат, оригинал цел;
- аварийное завершение core на каждом из 14 шагов (`ZAMOK_TEST_CRASH`), затем перезапуск: до шага `verified` оригинал на месте, а временная копия и журнал ждут; повторное шифрование доводит работу до конца с тем же содержимым. После шага `verified` папка зашифрована, открывается паролем, содержимое то же, оригинала и журнала нет;
- продолжение копирования (раздел G): после аварии на 20-м файле эти 20 файлов шифротекста остаются как были, Cryptomator читает результат; авария после записи файла до его сверки, изменённый, удалённый и новый файл в папке, испорченный файл шифротекста: в итоге ровно новое содержимое папки; другой пароль и повреждённая копия: откат и шифрование с нуля; шифрование другой папки откатывает прерванную копию первой; файл изменился посреди копирования: ошибка, копия ждёт, повтор без перезапуска core доделывает;
- в журнале core нет имён папок, путей и пароля.

Занимает около двух минут.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\core\test-encrypt.ps1
```

## Флешки exFAT и FAT32: буква диска

`test-letter.ps1`: 51 проверка режима флешки (DESIGN.md, раздел 3.6). Без параметров все папки только внутри `tests\tmp\letter` на NTFS, а core запускается с `ZAMOK_FORCE_LETTER_MODE=1` и считает любой том флешкой exFAT. С `-Drive G:` тот же прогон на настоящем диске exFAT или FAT32: данные только в `G:\zamok-test`, папка удаляется в конце; `-Big` добавляет шифрование файла 4,5 ГиБ (на флешке около 15 минут).

- шифрование: на месте папки обычная папка с файлом `Открыть <Имя>.zamok` и скрытым `desktop.ini`, хранилище рядом скрытое и системное, открытая папка на букве диска с меткой тома по имени папки, содержимое совпадает;
- чтение и запись на букве диска, запирание отключает букву, неверный пароль букву не подключает, открытие по пути файла открытия, Win+L и бездействие запирают и отключают;
- уход флешки (диск `subst` вместо флешки): по `DBT_DEVICEREMOVECOMPLETE` и без сообщения (проверка раз в 2 секунды) папка сразу запирается и становится «не подключена», через 8 секунд всё ещё в списке, открыть нельзя (`not_connected`); флешка под другой буквой находится по серийному номеру тома;
- аварийное завершение core на каждом из 14 шагов, как в `test-encrypt.ps1`;
- другой компьютер (чистая папка данных): `adopt_check` принимает файл открытия с настоящим хранилищем и отклоняет пустую `.Имя.zamok`, неверный пароль ничего не добавляет, верный добавляет папку с буквой диска и открывает её;
- FAT32 (`ZAMOK_FORCE_LETTER_MODE=fat32`): файл 4 ГиБ без байта отклоняется до копирования с его именем; на настоящем exFAT файл 4,5 ГиБ проверку проходит;
- Cryptomator читает хранилище; «Расшифровать навсегда» убирает заглушку и ставит на место обычную папку;
- в журнале core нет имён папок, путей и пароля.

Сбоку на время теста появляются диски `subst` (буквы от P: до W:) и буквы открытых папок (от Z: вниз), в конце они снимаются.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\core\test-letter.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests\core\test-letter.ps1 -Drive G:
```

## Расшифровать навсегда

`test-decrypt.ps1`: 15 проверок. Неверный пароль и открытый файл отклоняются, папка остаётся зашифрованной; после расшифровки папка обычная, содержимое совпадает с эталоном, даты файлов сохранены, хранилища, временной копии и журнала нет, папку можно зашифровать снова. Авария core на каждом из 7 шагов: до шага `copied` папка остаётся зашифрованной и открывается паролем, после него становится обычной с тем же содержимым.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\core\test-decrypt.ps1
```
