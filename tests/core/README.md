# Проверки фонового процесса (этап 4)

`test-core.ps1`: 38 проверок `zamok-core` на настоящей системе. Скрипт собирает core, создаёт хранилище из `tests/fixtures-src/vault1` и запускает core со своей папкой данных и своим каналом (переменные `ZAMOK_DATA_DIR` и `ZAMOK_PIPE`), поэтому настоящий core на этом компьютере не мешает и не затрагивается.

Что проверяется:
- права канала: доступ только у текущего пользователя; второй core с тем же каналом не запускается;
- добавление папки: подключается запертой, в ней один значок `Открыть <Имя>.zamok`, на точке подключения атрибут «системный»; плохое хранилище, хранилище внутри папки и занятый путь отклоняются, обычная папка на пути не трогается;
- открытие паролем, по пути значка, ключом восстановления; неверный пароль и неверный ключ оставляют папку запертой;
- запирание по команде, «запереть всё», по сообщениям Windows о блокировке экрана и сне (скрипт шлёт окну core те же сообщения, что Windows);
- запирание по бездействию: чтение раз в секунду держит папку открытой, без обращений она запирается сама;
- перезапуск: список и настройки сохраняются, папка подключается запертой;
- падение core: точка подключения исчезает, после запуска папка подключается снова;
- мёртвая точка подключения после выключения питания снимается при старте;
- обычная папка на месте зашифрованной: core её не трогает, папка «недоступна», после освобождения пути открывается;
- удаление из списка не трогает хранилище; в журнале нет имён папок, путей и пароля.

Запуск:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\core\test-core.ps1
```

Занимает около минуты. Нужен установленный WinFsp, папка `tests\tmp\core` пересоздаётся при каждом запуске.
