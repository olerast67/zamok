# Zamok: дорожная карта

Все шаги от пустого репозитория до публичной версии 1.0, без сроков. Этапы идут по порядку: следующий начинается, когда закрыт предыдущий, кроме скорости (этап 9), которая идёт параллельно с этапа 3. На GitHub каждому этапу соответствует веха (milestone).

Как устроена программа: [docs/DESIGN.md](docs/DESIGN.md). Из чего собирается: [docs/STACK.md](docs/STACK.md).
